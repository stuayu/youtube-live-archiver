# プライバシーと公開前の確認

## アプリが扱う情報

このアプリは、登録した YouTube チャンネルと動画の ID・名前・タイトル・説明・サムネイル URL、録画ファイルと保存先パス、チャット、文字起こし、処理履歴、設定をローカルの PostgreSQL とデータディレクトリに保存します。ログにも動画 ID、保存先、外部サービスのエラーなどが記録される場合があります。

文字起こしの要約を有効にした場合、要約処理に必要な本文が設定した OpenRouter API へ送信されます。YouTube の情報取得と画像取得では、それぞれの外部サービスへリクエストします。Cookie Profile を使う場合、認証情報は利用者が管理する Cookie ファイルまたはブラウザープロファイルから読み取ります。

## ネットワーク公開

アプリにはログイン認証がなく、CORS は任意の origin を許可します。既定の待受先は全インターフェースです。インターネットへ直接公開せず、信頼できるプライベートネットワーク内で使用してください。PC 内だけで使う場合は `APP_HOST=127.0.0.1` を設定します。LAN 外からアクセスする場合は、認証と TLS を提供するアクセス制御の内側に置き、未信頼ネットワークからの接続を遮断してください。

公開されるのはソースコードであり、アプリの HTTP サービスを公開インターネットに出すことを意味しません。

## リポジトリへ含めないデータ

次の情報やファイルは公開リポジトリへ追加しないでください。

- `backend/.env` などの実環境設定、API キー、DB パスワード、YouTube Cookie
- PostgreSQL のダンプ、`backend/data/`、録画・チャット・文字起こしのファイル
- ログ、スクリーンショット、画面録画、ユーザー名や端末名を含む絶対パス
- 実運用のチャンネル一覧、動画 ID、保存先、Cookie Profile、活動履歴を含む DB やサポート資料

`.gitignore` は代表的なローカル設定やデータを除外しますが、追加前の内容や Git 履歴までは保護しません。コミット前に `git status` と差分を確認してください。

## 公開前の確認

Gitleaks を利用できる場合は、現在の作業ツリーと全 Git 履歴を確認します。

```sh
gitleaks dir --redact=100 .
gitleaks git --log-opts="--all" --redact=100 .
```

スキャナーの結果だけに頼らず、作者名・メールアドレス、絶対パス、サンプル値、ログやテスト資料も目視で確認してください。認証情報が一度でもコミットされた場合、ファイルを削除するだけでは履歴から消えません。認証情報を失効・更新し、公開前に全ての公開対象 refs から該当内容を取り除いてください。既にリモートへ送信した情報は、履歴を書き換えても受信済みの複製から消せない場合があります。

自動テストと実配信検証の範囲は [E2E 検証手順](E2E_TESTING.md) を参照してください。
